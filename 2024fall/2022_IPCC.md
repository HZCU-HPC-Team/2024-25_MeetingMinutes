# 2022_IPCC

通过以下命令克隆项目：
git clone https://github.com/HZCU-HPC-Team/2022_IPCC.git

1.尽量读懂代码各项函数功能
2.运行代码，记录运行时间
3.通过以下命令使用vtune进行性能分析
source /opt/intel/oneapi/setvars.sh
vtune-backend --web-port 7070 --enable-server-profiling
4.借助AI建议和对于代码的理解尝试优化代码，缩短程序运行时间
5.使用overleaf编写报告，包括代码分析、性能分析、优化结果等
https://www.overleaf.com/project
可以选择New Project中的Example Project模板进行学习了解
